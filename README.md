# 🚀 Yashraj Gurjar | Developer Portfolio

A modern, responsive, and interactive personal portfolio website built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. This portfolio showcases my technical skills, education, certifications, projects, and career journey with a clean, futuristic UI and smooth user experience.

---

🔗 **Visit Portfolio:**  
https://yashrajsinghgujjar.vercel.app

## 👨‍💻 About The Project

This portfolio was designed to represent my journey as a **B.Tech Computer Science student** and an **Aspiring AI/ML Developer**.

The website focuses on providing a clean user experience with modern animations, responsive layouts, and interactive elements while maintaining excellent performance.

Whether viewed on desktop, tablet, or mobile devices, the portfolio delivers a consistent and professional experience.

# 📄 File Explanation

## 📌 index.html

The **index.html** file serves as the foundation of the entire portfolio website.

It defines the complete website structure and includes all major sections.

### Includes

- Navigation Bar
- Hero Section
- About Section
- Education
- Skills
- Certifications
- Projects
- Contact Form
- Footer

### Responsibilities

- Website Structure
- External CSS Linking
- JavaScript Linking
- Responsive Layout
- Semantic HTML
- SEO Friendly Structure

---

## 🎨 style.css

The **style.css** file controls the complete appearance of the website.

It transforms a simple HTML structure into a premium modern portfolio.

### Includes

- Dark Theme
- Glassmorphism
- Responsive Design
- CSS Grid
- Flexbox
- Animations
- Hover Effects
- Buttons
- Cards
- Typography
- Color Palette
- Mobile Layout

### Special Effects

- Smooth Transitions
- Glow Effects
- Circular Profile Image
- Responsive Cards
- Premium Buttons
- Modern Navigation

---

## ⚙ script.js

The **script.js** file adds life and interactivity to the portfolio.

It controls animations and user interactions.

### Features

- Mobile Navigation Toggle
- Auto Close Mobile Menu
- Animated Background
- Twinkling Stars
- Shooting Stars
- Canvas Animation
- Window Resize Handling
- Smooth Animation Loop

One of the major highlights is the custom **Night Sky Animation**, developed using the HTML5 Canvas API without relying on heavy animation libraries.
